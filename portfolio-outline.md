# TSA Webmaster Documentation Outline

Check the current-year TSA Webmaster guidelines for exact required items and page limits. Items below are a typical starting point.

## 1. Planning
- [ ] Problem statement and target audience (grades 9-12)
- [ ] Goals and success measures
- [ ] Team roles and timeline (Gantt or simple table)
- [ ] Sitemap (dashboard -> 3 modules -> badges -> about)
- [ ] Wireframes (sketch dashboard on desktop and phone)

## 2. Design
- [ ] Color palette with contrast ratios (aim for WCAG AA)
- [ ] Typography choices and why
- [ ] Style tokens (from `css/styles.css`)
- [ ] Screenshots: light and dark mode

## 3. Development
- [ ] Tech choices and why (HTML/CSS/JS, localStorage)
- [ ] How XP, levels, and badges work (diagram of `js/store.js` logic)
- [ ] Responsive strategy (breakpoints)
- [ ] Accessibility checklist
- [ ] Testing log: browsers, devices, bugs found and fixed

## 4. Content and Sources
- [ ] Source list for every fact (APA or MLA)
- [ ] Image/icon credits and licenses
- [ ] AI use disclosure: describe exactly how AI tools helped and what you wrote or verified yourself

## 5. Reflection
- [ ] What worked, what you would change
- [ ] User feedback from classmates and what you changed because of it
